# Tempo

{{#include ../../includes/human-review-disclaimer.md}}

The Tempo panel shows and sets the show tempo. Open it from the Command Palette. It is also in the default layout's right-hand edge panels.

The top of the panel shows the current BPM and a row of beat dots that follows the beat, with the larger dot marking beat 1 of the bar. Below that are fields for the exact tempo and the bar length, and a large **Tap** pad to tap along with the music. The toolbar holds **Half time**, **Double time**, **Resync to downbeat** and **Jump to next downbeat**.

See [Show tempo and tap tempo](../tempo.md) for how tapping and tempo changes behave.
