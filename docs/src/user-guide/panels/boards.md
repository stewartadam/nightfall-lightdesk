# Boards

{{#include ../../includes/human-review-disclaimer.md}}

Boards lists the show's boards: pages of buttons you arrange yourself for busking. Open it from the Command Palette. Use **Add board** (N) to create an empty board, which opens straight away in a [Board](board.md) panel in edit mode with its settings open so you can name it. **New Board** in the Command Palette does the same from anywhere.

Switch between the grid and list views with the buttons on the right of the toolbar. Each board shows its ID, label, number of elements, and whether the layout switcher lists it. Search by ID or label.

Click a card, press Enter, or Alt+click a row to open that board in its own Board panel; if a panel already shows it, that panel is brought to the front. Use **Edit selected board** (E) to change a board's ID or label; an ID another board already uses is refused. The right-click menu offers Open, Rename, and Delete, and Properties renames the selected board. Deleting a board removes it for every device; any Board panel showing it offers the other boards instead.

You can also open a board by typing its name in the object palette (Ctrl+P / Cmd+P).

## Boards in the layout switcher

Boards are listed after your layouts in the layout switcher at the top of the window. Picking one fills the whole workspace with that board, which suits a busking surface on a dedicated screen. Pick a layout, or open any panel, to return to your layout exactly as you left it. Which board is showing this way is remembered only on this device, for this session.

To keep a board out of the switcher, open **Manage layouts** (the + after the switcher) and clear its **Show in switcher** checkbox under **Boards**. This is saved in the showfile, so it applies on every device.

Boards are saved in the showfile and shared by every connected device. Board edits can be undone.
