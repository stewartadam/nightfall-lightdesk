# Cues

{{#include ../../includes/human-review-disclaimer.md}}

Cues lists stored cue objects across the show. Open it from the Command Palette, then search for a cue number or label. Cue addresses include their owning sequence: `1.2` means cue 2 of sequence 1.

Select a cue to inspect its properties; open it to enter [Cue Editor](cue-editor.md). Use this list to locate a look when you know its label but are not already in its Sequence Editor. Store new programmer content using Programmer's Store cue action.

A cue's stored instructions are distinct from the tracked output at that point in its sequence. If a cue appears to omit a value you see on stage, inspect the sequence's tracking behavior and preceding cues.

Use [Sequences](sequences.md) and [Sequence Editor](sequence-editor.md) for playback order, preview, setup/release programming, and timing. Review [Storing and recalling looks](../stores.md) before overwriting an existing cue.
